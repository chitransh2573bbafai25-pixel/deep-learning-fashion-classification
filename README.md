# Deep Learning Fashion Image Classification

This repository contains a Google Colab practical demonstrating how **Deep Learning** can be used to classify fashion product images.

## Topics Covered

* Deep Learning
* Artificial Neural Networks
* Image Classification
* Fashion MNIST Dataset
* Input, Hidden and Output Layers
* Model Training
* Model Accuracy
* Product Prediction
* Business Applications of AI

## Practical Overview

The project uses the **Fashion MNIST** dataset containing images of common fashion products such as T-shirts, trousers, dresses, shoes and bags.

A simple Artificial Neural Network is trained to classify images into **10 product categories**.

The model achieved a **test accuracy of 85.35%** in the practical run.

## Business Application

The practical demonstrates how an e-commerce company could use AI to automatically analyze product images and predict their categories.

### Possible Benefits

* Faster product listing
* Reduced repetitive manual work
* More consistent categorization
* Better product-search experience
* Processing larger numbers of product images

## Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Matplotlib
* Google Colab
* Fashion MNIST

## Key Learning

This practical demonstrates that Deep Learning can learn patterns from images and use those patterns to make predictions. It also highlights that model predictions are not always correct, so businesses should consider accuracy, risk and human review before deploying AI systems.
